# HBD 앙&밍 · iPhone 웹앱

하루 차이로 태어난 앙이와 밍이의 생일 놀이터. 기존 SwiftUI 앱의 화면과 기능을 모바일 웹으로 옮긴 PWA입니다. 아이폰 Safari에서 **홈 화면에 추가**하면 하단 탭이 있는 독립적인 앱 화면으로 실행됩니다. Apple 개발자 계정, 케이블, 개발용 서명 갱신이 필요하지 않습니다.

## 들어 있는 기능

- iOS 앱을 닮은 5개 하단 탭, 파스텔 카드, 아이폰 안전 영역 대응
- 작게 돌아다니는 밍꿍이·밍배, 홈 최하단의 조용한 표시 on/off 버튼
- 홈 상단 밍꿍이를 누르면 하트가 뿅뿅 나오는 효과
- 하단 커플 사진을 누르면 봉투가 열리며 나타나는 읽기 전용 편지
- 마이크로 불어서 끄는 촛불과 터치 대체 동작
- 기본 소원권 5장, 내용 변경과 사용/사용 취소
- 꿍찰권 직접 입력, 가중치 룰렛, 이월 판돈
- 기본 사진 9장, 사진 추가·삭제, 사진별 메모
- IndexedDB 로컬 저장, JSON 백업·복원, 기본 사진을 포함한 오프라인 캐시

## 소스 내려받고 로컬에서 실행

Node.js **22.13 이상**(Node 22 LTS 권장), npm, Git을 준비합니다. Xcode는 필요 없습니다.

```bash
git clone https://github.com/minwoocho/abngandmingweb.git
cd abngandmingweb
npm ci
npm run dev
```

터미널에 표시된 로컬 주소(기본 `http://127.0.0.1:5173`)를 브라우저에서 엽니다.

```bash
npm test          # 룰렛 확률, 정산, 0장 및 이월금 회귀 테스트
npm run build    # TypeScript 검사 + 정적 빌드 + 오프라인 서비스 워커 생성
npm run preview  # 빌드 결과 확인 (기본 http://127.0.0.1:4173)
```

모바일 Chromium 및 Safari 엔진(WebKit)의 통합 테스트도 포함되어 있습니다. 사진 추가·메모 저장·백업 복원·하단 탭·0장 룰렛·오프라인 재실행을 실제 배포 하위 경로에서 검사합니다.

```bash
npx playwright install chromium webkit
npm run build
npm run test:e2e
```

개발 서버에서는 서비스 워커가 동작하지 않습니다. 오프라인 기능은 `build` 후 `preview` 또는 HTTPS 배포 주소에서 확인합니다. 아이폰에서 PC의 LAN IP를 HTTP로 열면 화면은 볼 수 있어도 마이크·서비스 워커가 제한될 수 있으므로, 실기기 확인에는 HTTPS 배포 주소를 사용하세요.

## GitHub Actions로 배포

이 저장소는 서버나 Cloudflare 없이 **GitHub Pages**에 올릴 수 있습니다. `.github/workflows/pages.yml`에 테스트 → 빌드 → 배포 작업이 구성되어 있습니다.

1. GitHub 저장소 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**를 **GitHub Actions**로 선택합니다.
3. **Actions → Deploy birthday PWA to GitHub Pages → Run workflow**를 실행합니다. 이후 `main`에 푸시하면 자동으로 실행됩니다.
4. 완료 후 배포 주소를 확인합니다. 기본 주소는 `https://minwoocho.github.io/abngandmingweb/`입니다.

Pages를 아직 활성화하지 않았다면 첫 배포 작업이 실패할 수 있습니다. 위 설정을 완료한 뒤 다시 실행하세요. 비공개 저장소의 Pages 사용 가능 여부는 GitHub 요금제에 따라 달라집니다.

`vite.config.ts`의 상대 경로 설정 덕분에 저장소 하위 경로에서도 이미지·아이콘·서비스 워커가 동작합니다. 다른 정적 호스팅에서는 `dist/` 폴더를 배포하면 됩니다. HTTPS가 필요하며, 화면 이동은 해시(`#home`, `#album` 등)를 사용해 별도의 서버 라우팅 설정은 필요하지 않습니다.

## 여자친구 아이폰에 설치하기

1. 배포된 HTTPS 링크를 전달합니다.
2. 아이폰의 **Safari**에서 링크를 엽니다. 카카오톡 등의 앱 안 브라우저에서는 Safari로 열기를 선택하세요.
3. 홈 하단 **홈 화면에 추가 · 보관함**에서 **오프라인 준비 완료** 표시를 확인합니다. 기본 사진 다운로드를 위해 첫 실행 시 인터넷 연결이 필요합니다.
4. Safari **공유 → 홈 화면에 추가 → 추가**를 선택합니다. **웹 앱으로 열기** 옵션이 있으면 켜주세요.
5. 홈 화면의 **HBD 앙&밍** 아이콘으로 실행합니다. 처음 실행도 인터넷에 연결한 상태에서 진행하세요.

마이크 권한은 촛불 화면에서 마이크 버튼을 눌렀을 때만 요청합니다. 녹음하거나 서버에 음성을 전송하지 않으며, 촛불을 끄거나 다른 탭으로 이동하면 마이크를 종료합니다. 권한을 거절해도 촛불 터치로 사용할 수 있습니다.

네이티브 개발 앱과 달리 7일/90일 서명 만료가 없습니다. 다만 사이트가 유지돼야 새로 설치하고 업데이트할 수 있고, 브라우저가 오프라인 캐시를 제거하면 다시 인터넷 연결이 필요합니다. ‘한 번 설치하면 영구 보장’되는 저장 방식은 아닙니다.

## 데이터 저장과 다른 기기로 옮기기

모든 개인 기록은 **해당 기기의 해당 웹앱 저장소(IndexedDB)**에 저장됩니다. 서버 DB나 로그인은 없고, 두 사람 사이에 자동으로 동기화되지 않습니다. 기본 사진·캐릭터·편지는 앱에 포함되지만, 사용자가 추가한 사진·메모는 업로드 서버로 전송되지 않습니다.

- 홈 하단 **홈 화면에 추가 · 보관함 → 백업 파일 저장**으로 사진·메모·소원권·꿍찰권·표시 설정을 JSON 파일에 저장합니다.
- 파일 앱에 보관하거나 다른 기기로 보내고, 해당 기기에서 **백업 파일 불러오기**를 선택합니다.
- 복원은 현재 기기 데이터를 백업 내용으로 교체합니다. 기존 기록을 먼저 백업하세요.
- 기본 사진은 백업에서 파일 경로로 참조하고, 사용자가 추가한 사진은 이미지 데이터까지 포함합니다.
- Safari 방문 기록/사이트 데이터 삭제, 기기 교체, 저장 공간 정리로 기록이 사라질 수 있습니다. 중요한 사진과 메모는 정기적으로 백업하세요.
- Safari 탭과 홈 화면 웹앱의 저장소가 항상 공유된다고 가정하지 마세요. 평소에는 홈 화면 아이콘으로 실행하고, 필요하면 백업으로 옮기세요.
- 기존 네이티브 iOS 앱의 SwiftData 및 사진은 자동으로 가져오지 않습니다.

사진은 선택 시 긴 변을 최대 2,000px로 줄이고 JPEG로 저장합니다(서버 전송 없음). 기본 제공 HEIC 사진도 웹 호환 JPEG로 변환했습니다. 브라우저가 해석하지 못하는 HEIC 파일은 JPEG/PNG로 변환해 추가하세요. 백업 복원은 100MB 이하 파일을 지원합니다.

저장소 및 정적 사이트에 포함한 **기본 사진과 편지는 접근 가능한 방문자가 내려받을 수 있습니다.** 이 웹앱에는 접근 제어가 없습니다. 새로 추가한 로컬 사진과 백업 파일은 Git에 올리지 마세요.

## 내용 변경

- 편지: `src/content.ts`의 `letter`를 수정하고 푸시합니다. 현재는 요청한 애국가 임시 문구입니다. 앱 내부에는 편지 수정 UI가 없습니다.
- 기본 소원권: `src/content.ts`의 `defaultWishes`를 수정합니다. 이미 저장된 사용자 소원권은 덮어쓰지 않습니다.
- 기본 사진: `public/photos/default-01.jpg` ~ `default-09.jpg`
- 캐릭터와 커플 누끼: `public/characters/`
- 아이콘: `public/icons/`, 앱 이름: `index.html` 및 `public/manifest.webmanifest`
- 스타일: `src/styles.css`, 룰렛 규칙: `src/game.mjs`

룰렛은 2배 16%, +5회 12%, 3배 6%, +2회 18%, 나머지 ½배 4%, 꽝 14%, -1회 10%, -2회 10%, 묻고 더블로 10%입니다. 판돈은 먼저 차감하고 이월금은 다음 배팅에 합칩니다. 보유량이 0장이어도 이월금이 있으면 계속 돌릴 수 있습니다. 결과를 먼저 저장한 후 회전 애니메이션을 보여주므로 새로고침으로 판돈을 복구하지 않습니다.

새 버전이 내려받아지면 홈 보관함에서 **새 버전으로 업데이트**를 눌러 적용할 수 있습니다. 업데이트는 오프라인 앱 캐시만 바꾸고 IndexedDB의 개인 기록은 지우지 않습니다.

## 저장소 구성

```text
src/                 화면, 로컬 저장, 룰렛 규칙, 편지
public/              기본 사진, 캐릭터, 앱 아이콘, PWA manifest
scripts/build-pwa.mjs 빌드 결과 기반 오프라인 캐시 생성
tests/               룰렛 회귀 테스트
.github/workflows/   GitHub Pages 자동 배포
```

`.gitignore`는 의존성(`node_modules`), 빌드 결과(`dist`), 테스트 결과, 개인 환경 파일 및 백업 JSON을 제외합니다. 재현 가능한 설치를 위해 `package-lock.json`은 포함합니다. 기존 네이티브 앱의 Xcode 프로젝트와 빌드 캐시는 이 웹 전용 저장소에 포함하지 않습니다.
